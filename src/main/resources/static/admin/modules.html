💡 ¿Cómo funciona el encendido y apagado de módulos en Vazzar?

Cada Bounded Context (identity, inventory, billing, ecommerce, fair) posee su propio esquema de PostgreSQL aislado y su propia arquitectura hexagonal (dominio, aplicación, infraestructura).

Cuando un módulo es APAGADO, el interceptor central de Spring Boot bloquea inmediatamente el acceso a sus rutas con un código HTTP 503 Service Unavailable sin procesar peticiones ni tocar la base de datos. Al ENCENDERLO, sus endpoints y servicios vuelven a responder con normalidad en tiempo real.
